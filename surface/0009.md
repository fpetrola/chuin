## Need

MovingFocusWithTabTest needs Tab to move the focus to the next button so that Enter presses that one. The desktop must tell Tab from Enter from any other key, which comparing instances no longer covers. A package-private KeyVisitor lets each key say which it is (enter, tab, other) through Key#accept, so the desktop moves focus on tab and presses on enter without casts or instanceof; the keyboard turns a tab byte into Keys#tab().

## Considered

Keys#enter() is the only key a client can name, and the sealed Key has no members, so the only way to tell keys apart today is comparing a key with the Enter instance; that cannot tell Tab from any other key.
