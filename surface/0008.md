## Need

ChangingALabelTest needs a window to show text that changes while the desktop runs: a Label made by the toolkit, placed in a window at a position like a button, whose text a button listener can change, and which the next draw shows. Drawing stays in the visitor: ViewVisitor#label hands the painter the label's current text, so no class grows methods of its own.

## Considered

Window#add(Button, Point) only places buttons, and a button's caption is fixed when Toolkit#button(String) makes it; nothing sealed shows text that can change. ViewVisitor#button(Button, String, List<ButtonListener>) hands over a caption but is about something that can be pressed.
