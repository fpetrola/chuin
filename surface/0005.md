## Need

TypingOnAKeyboardTest needs keys to come from a real input instead of being built by the client: a Keyboard over any InputStream that reads bytes until the stream ends, turns each into a key (carriage return is Enter) and types it into a desktop. With System.in the stream never ends, so typeInto is also the demo's event loop.

## Considered

Desktop#type(Key) takes a key but only Keys#enter() makes one, and nothing sealed reads keys from outside the process; a client would have to translate bytes into keys itself.
