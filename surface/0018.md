## Grows

  - `com.fpetrola.tui.KeyVisitor#function(int): void`

## Need

SwitchingWindowsTest needs F6 to bring the window below to the top, the way Turbo Vision cycles windows, with each window keeping its own focus. Terminals send function keys as escape sequences (ESC O P..S for F1-F4, ESC [ n ~ for F1-F12), and the keyboard must hand them over as keys a visitor can tell apart, which the sealed KeyVisitor cannot express today.

## Considered

KeyVisitor#other() is what a function key turns into today, so F6 cannot be told from Home or Delete. One method per key (f1() to f12()) would grow the sealed surface twelve times for keys nothing uses yet; a number keeps it at one member, and the desktop only acts on 6.
