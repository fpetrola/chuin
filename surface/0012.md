## Need

This is a move, not a change: module tui is split into tui-api, which holds every sealed interface, and tui-text, which holds TextToolkit and the classes that implement them, with tui-demo now depending on tui-text. Every signature in Grows is identical to one already signed in .cerco/surface/tui.txt (and Demo#main in tui-demo.txt); only the module that owns it changes. Everything stays in package com.fpetrola.tui so the visitors stay package-private.

## Considered

TextToolkit#<init>() is sealed in module tui, which no longer exists in the reactor; the members cannot stay sealed under a module that is gone, so they are sealed again under the module that now holds them.
