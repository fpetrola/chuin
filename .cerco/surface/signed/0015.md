## Need

MovingAWindowWithArrowsTest needs the arrow keys to move the top window one cell each, the way a Turbo Vision window is dragged from the keyboard. A terminal sends each arrow as an escape sequence (ESC [ A..D); the keyboard must turn those into keys a visitor can tell apart, which the sealed KeyVisitor cannot express today.

## Considered

KeyVisitor#other() is what each byte of an arrow's escape sequence turns into today, so the desktop cannot know an arrow was pressed, let alone which; KeyVisitor#character(char) would leak the raw '[' and 'A' into input lines. Window#place(Area) already moves a window, so nothing grows on Window.
