## Need

The README shows how the toolkit is used with several examples and two larger demos, each with its screenshot, and Fernando asked for their code to live in tui-demo so it is not lost. The demo had one application built inside Demo itself, so there was no way to run, test or picture any other. Example is what each of them is: Example#name() is what it is called on the command line (./demo.sh lists), and Example#build(Toolkit, Desktop) puts its windows, menu bar and status line on a desktop. Demo runs the one named, the address book when none is; DemoTest runs them through main, and TakingScreenshotsTest builds each one, poses it (a menu or a drop down opened with a click), draws it and, with -Dscreenshots, writes the PNG the README shows. The Spanish address card that was Demo's is replaced by the English address book, as the README is in English.

## Considered
