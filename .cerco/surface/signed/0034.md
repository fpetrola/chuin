## Need

Fernando pointed out that the visitor was still wrong: a window offered several ways in (accept, acceptViews, acceptChildren), so each visitor chose which part to walk and had to know how a window is put together. In a visitor only the element knows its structure: Window#accept visits the window and then each of its placements, and a placement visits itself and then its view. A visitor that does not care about a part does nothing when it meets it.

## Considered

Window#accept(ViewVisitor) visited only the window itself, so the views were reached through the other ways in that this removes. Giving each view its own position, as Turbo Vision's origin, was weighed and left out: the position is a relation between window and view, so it lives in the placement that Window#accept now goes through.
