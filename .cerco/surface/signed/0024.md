## Need

ViewVisitor#inputLine handed every visitor the input line's inner state already taken apart (its text, width, a Consumer to type and a Runnable to erase), so it was not a visitor but a destructuring, and InputLine itself said nothing: the application needed a separate getter to read its text. Fernando asked for a classic visitor: the visitor receives only the InputLine, and the line answers for its own state and behaviour.

## Considered

ViewVisitor#inputLine(InputLine, String, int, Consumer<Character>, Runnable) is the member this replaces: every new piece of state would change its signature and every visitor, as erase did in 0014. InputLine#text() already exists for the application and is now what the painter reads too, so there is one way to the text instead of two.

## Removes

- `com.fpetrola.tui.ViewVisitor#inputLine(InputLine, String, int, Consumer<Character>, Runnable): void`
