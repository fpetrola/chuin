  - `com.fpetrola.tui.Toolkit#escapeKey(): Key`

## Need

Keys, the last name plural-name froze, made the named keys a program binds (Enter, Tab, Space, F1 to F12, Esc) beside Toolkit, which already makes every other piece of the framework. Instead of renaming a second factory, its five methods move to Toolkit as enterKey, tabKey, spaceKey, functionKey(int) and escapeKey, and Keys, TextKeys and Toolkit#keys() go away. The keyboard builds Space, Tab and Enter itself, as it builds every other key. Same keys, same behaviour; the tests change only in where they get them from.

## Considered

`com.fpetrola.tui.Desktop#bind(Key, Runnable): void` takes a Key but gives no way to get one by name; `com.fpetrola.tui.Toolkit#point(int, int): Point` shows where the framework's pieces are made, and the named keys belong beside it. The keys used to come from Keys, a second factory with a frozen plural name that this proposal takes away.
