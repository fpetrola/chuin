## Need

ErasingWithBackspaceTest needs the backspace byte (0x7F) to erase the last letter of the focused input line. The keyboard must tell backspace apart from other bytes (KeyVisitor#backspace), and the input line must hand the visitor how to erase its last character next to how to type one, so the desktop erases from the focused line without casts.

## Considered

KeyVisitor#other() is what backspace turns into today and it cannot be told apart from any other byte; ViewVisitor#inputLine(InputLine, String, int, Consumer<Character>) only lets characters be added, never taken away.

## Removes
