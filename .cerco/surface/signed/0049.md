## Need

Step 5c of PLAN.md: a menu like Quadra's Datei shows on each item's right the key that runs it ("Laden  F3") and lines between groups of items that the arrows step over. As in Turbo Vision, where a TMenuItem takes its key, an item must take the key itself, so the name shown comes from the key and the desktop binds it when the bar is shown; a menu must take a separator, and visiting a menu must meet its separators in order between its items.

## Considered

Menu#add(String, Runnable) takes only the item's text. Desktop#bind(Key, Runnable) runs F3 from anywhere but the menu would not know it; a first draft took the shortcut as a String to show, which cerco-tdd-97 turned down because the menu could then show F3 while F3 does something else or nothing.
