## Need

SeeingColorsTest needs each cell of the screen to say how it is colored, not only which character it holds, so windows, the focused view and shadows can be told apart the way Turbo Vision paints them. The screen must take a tint for a run of cells (Screen#paint) and hand back one tint per cell (Screen#tints), cut at the edges like write, so a terminal can later turn each tint into ANSI colors.

## Considered

Screen#write(int, int, String) and Screen#lines() only carry characters; folding color into the text (escape codes inside the lines) would break every test that compares lines and make widths lie. A tint is a palette letter rather than a Color type so tests can read whole rows at a glance, as they read lines. The palette is documented on Screen#tints itself, not only in DECISIONS.
