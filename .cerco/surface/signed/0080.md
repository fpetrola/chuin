## Need

The project is now called chuin: its GitHub repository is fpetrola/chuin and the README names it so. Fernando asked for everything that can carry the name to carry it, so the modules tui-api, tui-text and tui-demo become chuin-api, chuin-text and chuin-demo, the packages com.fpetrola.tui become com.fpetrola.chuin, and the root artifact cerco-tdd becomes chuin. This is a rename only: every type and member keeps its name, its signature and what it promises; nothing is added and nothing is taken away. Tests change only their package line, with one exception: in ScrollingAWindowTest the two BarTarget variables are now declared as ClickTarget, so the contract names the interface they already exercised through click(). The seal keys each member by module and full name, so each sealed member reappears under the new name and the old one goes.

## Considered

`com.fpetrola.tui.Toolkit#desktop(): Desktop` and every other sealed member already say all of this, but under the module and package names the project no longer has; keeping tui only to keep the seal would leave the code named after a project that is not this one.
