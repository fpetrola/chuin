## Need

TextDesktop implemented Desktop but threw UnsupportedOperationException from show(MenuBar) and bind(Key, Runnable), since MenuDesktop took over the menu bar and the bindings it is only the windows of a desktop, wrapped by MenuDesktop. A class that promises a contract and refuses half of it breaks the first time someone uses it directly; cerco-tdd-97 caught it. The windows need an interface of their own with only what they do: open, take keys and clicks, and draw.

## Considered

Desktop#open(Window), Desktop#type(Key), Desktop#click(Point) and Desktop#draw(Screen) are exactly what the windows do, but Desktop also has Desktop#show(MenuBar) and Desktop#bind(Key, Runnable), which only the menu desktop around them can honour, so TextDesktop cannot be a Desktop honestly.
