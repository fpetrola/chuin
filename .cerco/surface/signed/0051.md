## Need

Windows#escape must close an open list or, when there was none, run the binding it was given; which one is only known once the visit of the focused view is over, since a view that is not an open drop down is never told so. Commit 5dd1d3a kept that answer in a boolean[] the caller set and read back, the same flag no-ignored-result had flagged, only hidden in an array; cerco-tdd-97 caught it. The visitor that observes should decide, and run what is still due once the visit is over.

## Considered

Windows#escape(Runnable) is the entry, and ViewVisitor#visitHighlightedDropDownItem(DropDownItem) is where an open list is met, but no visit says it is over. Drawing#drawOn(Screen) runs something once, yet it means drawing on a screen, and using it here would be borrowing a concept the way Consumer<Screen> was.
