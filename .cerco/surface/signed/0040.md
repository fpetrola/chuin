## Need

SeeingTheActiveWindowTest needs the window on top drawn with a double frame and the others with a single one, as Turbo Vision shows the active window. A frame must be drawable with either set of lines. Commit fe50ec0 did it with an enum whose characters were non-private fields read by Frame, which unpromised-member rejects; a border must draw its own rows instead of handing its characters over, so it needs an interface of its own.

## Considered

Drawing#drawOn(Screen) draws a whole thing onto a screen, but a border is only the rows of a frame and needs the inner width and the label to draw them, so it is not a Drawing. Static factories Frame.single and Frame.doubled were tried and rejected by cerco as new entrances to the module.
