## Need

Fernando asked for chuin-text, whose 94 classes all sit in one flat package, to be split into packages that fit what each class is. Everything in chuin-text goes under com.fpetrola.chuin.text, apart from the API, so no package is split between the two modules. This is the first step, geometry, the bottom of the dependency order (menu, desktop, paint, pointer/view, screen, geometry), with no package cycles. TextArea, TextPoint, TextSize, Extent and TextExtent move to com.fpetrola.chuin.text.geometry. Every other package will use them, so Extent and its members become public, and so does TextExtent's constructor, which is how the rest of the module gets an Extent for an area (in TextDesktop, Painter and ClippedScreen). Nothing changes in behaviour or signature, only the package and the visibility.

## Considered

`com.fpetrola.chuin.geometry.Area#column(): int` and the rest of the sealed Area in chuin-api say where an area is and how big, but not which cells it covers, the part another area shows of it, or a cell counted from its corner; that is what Extent says. The Extent sealed so far (com.fpetrola.chuin.Extent, taken back under Removes) said it too, but in the flat package and package-private, so the classes that will live in text.screen, text.paint and text.desktop could not reach it. The records TextArea, TextPoint and TextSize need no signature because cerco does not ask one of a record.
