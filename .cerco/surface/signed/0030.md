  - `com.fpetrola.tui.Window#acceptViews(ViewVisitor): void`

## Need

ViewVisitor#visitWindow(Window) had a default body that walked the window's children itself (acceptChildren, then accept on each view), so the visitor interface knew how a window is put together. Fernando pointed out that walking its views belongs to Window. The window must offer to have a visitor visit each of its views, and the visitor only decides whether to go in; visitWindow's default does nothing.

## Considered

Window#acceptChildren(ChildVisitor) walks the views with their positions, which the painter needs, but a visitor that only wants the views would have to write the same lambda the default had. Having Window#accept(ViewVisitor) always go into the children was considered and dropped: the painter would get the views without their positions.
