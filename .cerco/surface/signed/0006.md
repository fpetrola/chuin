## Need

RunningOnAConsoleTest needs a running desktop to be seen on a console: shown once at start and shown again after every key read, until the input ends. A Console built over an input, an output and a screen runs a desktop that way, so a demo is one call with System.in and System.out. Inside it reuses Keyboard, Terminal and Desktop#draw, already sealed.

## Considered

Keyboard#typeInto(Desktop) types every key into the desktop but never draws, and Terminal#show(Screen) shows a screen only when asked; nothing sealed redraws between keys, so a client would have to write that loop itself.
