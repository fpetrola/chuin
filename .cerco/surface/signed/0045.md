## Need

Step 5 of PLAN.md starts with keys bound on the desktop: F3 must run Laden whatever view has the focus, the way Turbo Vision's commands work, and the status line and menu shortcuts will build on that. The desktop must take a key and a command, and code must be able to name a function key, F1 to F12, the same way the keyboard reads it whichever sequence the terminal sent.

## Considered

Menu#add(String, Runnable) runs a command only from an open menu, and Button#onPress(ButtonListener) only from its button, so neither reaches a command from anywhere. Keys#enter(), Keys#tab() and Keys#space() name only those three keys; a function key could only be typed, not named, until now.
