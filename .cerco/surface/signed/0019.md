## Grows

- tui-api
  - `com.fpetrola.tui.KeyVisitor#control(char): void`

## Need

ClosingAWindowTest needs Ctrl+W to close the top window, giving the focus back to the window below as it was. A terminal sends Ctrl with a letter as a single byte from 0x01 to 0x1A; today those bytes all become KeyVisitor#other(), so the desktop cannot tell Ctrl+W from any other control byte. The keyboard must hand them over as control keys named by their letter.

## Considered

KeyVisitor#function(int) could carry Alt+F3, Turbo Vision's close key, but terminals send Alt+F3 in too many ways to read reliably; KeyVisitor#other() loses which byte came. One method per letter would grow 26 members; one control(char) keeps it at one, as function(int) did.
