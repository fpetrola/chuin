## Need

ChoosingFromAMenuTest needs menus with items that run a command: F10 opens the first menu as a box under its title, the arrows walk its items and the other menus, Enter runs the selected item and closes the menu, and F10 closes it again; while a menu is open no key reaches the windows. Menu must take items with their commands and walk them, so the desktop can draw the open menu and run the chosen command.

## Considered

Button#onPress(ButtonListener) runs code when chosen, but a ButtonListener is told which Button was pressed and a menu item is not a view of a window. ListBox#acceptRows(ListRowVisitor) walks rows with a selection, but the selection of an open menu belongs to the desktop for as long as it is open, not to the Menu, so items are walked plainly and the desktop keeps which one is selected.
