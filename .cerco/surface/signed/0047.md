## Need

Step 5b of PLAN.md: a status line across the bottom row, as in Turbo Vision and Quadra, whose entries show their key highlighted ("~F3~ Laden"), run on that key from anywhere and on a click, and cover the windows under them. The toolkit must build it, the desktop must show it and bind each entry's key, and the line must be walked, line then entries, to be drawn and clicked; the escape key must be nameable to bind "Esc Raus hier".

## Considered

Desktop#bind(Key, Runnable) already runs a command on a key from anywhere, and the status line builds on it, but a binding shows nothing and cannot be clicked. Desktop#show(MenuBar) shows the top row; a menu bar opens menus instead of running commands, so the bottom row needs its own kind of line. Keys#function(int) names F1 to F12 but not Escape.
